# 査読追加実験の固定プロトコル

2026-09-11。追加結果の算出前に設定。提出時の結果を見た後に設計した追試であり、研究全体の事前登録ではない。

- 入力：既存の276質問、510文書、Dense埋め込み、Query2doc通常・カテゴリ条件付き各276擬似文書。生成APIは使わない。
- 外側分割：既存の根拠文書単位5-fold、seed 20260802を完全再利用。元質問にも省略質問の開発側で選択した設定を適用。
- 質問語の扱い：提出時のbinaryと、出現回数を線形重みとして使うcountの両条件。count条件ではBM25、疎密統合、RRF、RM3の初回検索も同じ基準とする。RM3の補間モデルは従来どおり語頻度を使う。
- Query2doc：文字列連結の境界bigramを避けるため、別々にtokenizeした質問・擬似文書について `n*Counter(query)+Counter(pseudo)` を主たる修正条件とする。n=1,5を比較。提出実装と同じ文字列連結+[SEP]のcount条件も診断用に算出し、語頻度効果と連結方式の効果を分離する。
- 固定パラメータ：k1=1.2、b=0.75、RM3 feedback docs=10、terms=10、original weight=0.5、mu=1000、RRF k=60、Query2doc n=5。
- 調整グリッド：BM25 k1={0.6,1.2,1.8,2.4}×b={0,0.25,0.5,0.75,1}（20候補）。RM3はこの20候補×original weight={0.25,0.5,0.75}×terms={5,10,20}（180候補）。Hybridは20候補×alpha={0,0.1,...,1}（220候補）。RRFはBM25の20候補とk={10,30,60,100}（80候補）。Query2docはBM25の20候補、n=5固定（生成を含むプロンプト探索はしない）。
- 調整は各外側foldの開発側省略質問MRR最大。数値誤差1e-12以内の同点では固定値に近い候補を優先。調整する場所は揃えるが探索候補数は等しくない。この制限を明示する。
- 保存：全候補の質問単位正解順位、外側fold選択、入力SHA256。データ・キャッシュ・提出時の結果は上書きしない。
- 推論：根拠文書単位符号反転100,000回、クラスタbootstrap100,000回。質問を等重みとし、文書クラスタを再標本化。固定されたOOF予測についての条件付き推論であり、学習・選択の全不確実性を含まない。6手法対BM25のMRR検定はHolm補正。省略×手法の利得差を主たる追加分析とする。
- ルーティングを再評価するときは、外側評価foldを完全に除いた開発集合内で内側grouped CVを実行し、そのOOF結果で全体・カテゴリ別の手法を選ぶ。外側OOFの開発行を再利用するだけでは、外側評価ラベルが間接的に入るため不十分。
- Query2docの元質問生成は未実施。元質問に省略質問用の擬似文書を流用しない。省略前後比較は生成を必要としない5手法で行う。
